# List of Programs

1. Function Overloading – Demonstrates compile-time polymorphism using overloaded functions.
2. Area Calculator using Function Overloading – Calculates area of different shapes using overloaded methods.
3. Unary Minus Operator Overloading – Overloads unary minus for user-defined objects.
4. Prefix and Postfix Increment Operator – Demonstrates ++ and -- operator overloading.
5. Complex Number Addition using '+' Operator – Adds complex numbers through operator overloading.
6. Relational Operator Overloading – Implements comparison operators for objects.
7. Friend Non-Member Operator – Uses friend functions for operator overloading.
8. Base Pointer without Virtual Function – Demonstrates static binding.
9. Base Pointer with Virtual Function – Demonstrates runtime polymorphism.
10. Base Reference with Virtual Function – Shows dynamic dispatch using references.
11. Abstract Class – Demonstrates pure virtual functions.
12. Collection of Shape Pointers – Uses polymorphism with collections of objects.
13. Virtual Destructor – Demonstrates proper cleanup in inheritance hierarchies.
14. Object Slicing – Explains loss of derived-class information during copying.
15. Payment Processing System – Mini project using polymorphism.
16. Employee Payroll Mini Project – Real-world payroll management example using OOP.
